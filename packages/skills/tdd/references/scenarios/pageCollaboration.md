# 场景：与页面协作（截图核验 / 人机共存）

适用：需要肉眼看画布（核验布局/节点内容）、或用户同时在页面上操作。

## 截图核验

```bash
# 1. 让已打开的页面把视口适配到全部节点（或聚焦指定节点）
tdd canvas fit
tdd canvas fit --nodes 分镜1,主角          # 节点多时分组逐区截图，避免缩太小看不清

# 2. 用你宿主的内嵌浏览器截图（agent 自有能力）
```

- fit 是**页面动作**：需要有一页 Toonflow 打开（无页面时报错并提示，先用内嵌浏览器打开 `http://127.0.0.1:3000` 对应页面再重试）。
- 截图前先 `canvas report` 拿节点清单，规划分组。

## 人机共存（页面与 CLI 并行操作）

- 画布文档有 revision 乐观锁：后写方若基于过期版本会得到 409（CLI 退 3）。
- CLI 侧遇到 409：`tdd canvas get` 重读最新画布，重放你的修改。
- 页面侧会收到重载提示（用户自行确认），互不覆盖。
- CLI 建的新画布对页面实时可见（打开切换器即重扫）；同理页面建画布后 CLI `canvas list` 也能看到。

## 挂机期间的用户行为

用户随时可能打开画布查看、微调节点——属正常协作；你的批量任务以磁盘文档为准，不受页面状态影响。个别 409 按上述处理即可。
