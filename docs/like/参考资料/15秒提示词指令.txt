 一、顶层核心总纲
【按需解析规则】
粘贴原始小说 / 剧本文本，无需手动标记摘抄台词；模型自动语义区分三类文本，严格忠于原文，禁止杜撰新增内容：
1. 角色对外对白：引号包裹角色口头对话，原文存在则完整抓取填入台词位；强制附带【对视对象：XX 角色】标签。叙事优先级策略：优先使用角色对外对白承载人物心理活动、吐槽、世界观背景信息；仅原文明确写明暗道 / 心想 / 心底暗想，才启用内心独白；禁止无依据主动生成内心独白。
2. 内心独白：暗道 / 心想 / 心底暗想类心理活动，原文真实存在才提取，填入台词位，不添加对视对象标签，调用该角色内心独白专用声线模组。
3. 第三方旁白叙事：上帝视角客观叙事，原文真实存在才提取，填入台词位，不添加对视对象标签，调用旁白专用声线模组；禁止无原文依据主动生成上帝视角旁白。

> 时长拆分标准：严格依据原文拆分输出14.7‑15.3 秒镜头单元；单段对话在角色自然情绪语速 + 合理情绪停顿下超出 14.5s，必须在对话切换、情绪转折节点拆分为多个 15 秒镜头单元；优先按照剧情节点、情绪转折、对话切换做镜头切分，不做纯粹机械时间切片；禁止靠提高语速强行挤压进单镜头；镜头数量跟随剧情动态生成，剧情拆解完毕即停止，不硬凑占位镜头。

【帧接续核心约束（最高优先级，新增双模式机制）】
帧接续是实现分镜头之间流畅观感的手段，不可牺牲人物情绪与剧情感。
> 模式A【AI软帧接续‑默认模式】：同一时空、时间连续剧情启用本模式
1. 同一时空执行帧接续，完整继承上镜头全部角色资产、服饰造型、配饰、道具、光影、薄雾、倒影、环境粒子、视线锚点、运镜末端参数；上镜头末帧姿态仅作为动作推演起始基准，静态展示时长严禁超过 0.8s，继承后立刻执行台词 / 动作 / 情绪微表演，禁止直接复刻末帧姿态做长时间摆 pose 入场铺垫。
2. 冲突推进镜头`0‑3s`区间，必须落地六者至少一项：角色对白 /（原文存在才启用）内心独白 /（原文存在才启用）旁白 / 冲突动作 / 危机交互 /带情绪的人物微表情反应；禁止 0‑3s 只做人物入场、站定摆姿、单纯环境展示，把冲突向后拖延。
3. 同一时空同一剧情强制连续画面流衔接，禁止无理由硬切；运镜轨迹从上镜头末尾继续推演，禁止重置运镜。
4. 每一个镜头结尾必须写【衔接前置：帧接续基准锁定】，固化本镜头末帧全部画面参数，作为下一个镜头动作推演起始基准，该基准姿态禁止冻结静态展示大于 0.8s；非场景 / 时间跳转禁止硬切。

> 模式B【剧情硬切模式】：**仅场景剧变、时间跳变、昼夜切换、空间完全置换、战斗多短镜头剪辑场景允许开启此模式**
1. 硬切强制保全角色资产、五官、发型、服饰、配饰、道具、光影参数统一，不得篡改人物形象与资产；
2. 硬切模式下，**不强制继承人物肢体姿态、手部位置、运镜末端轨迹**，可直接切入全新动作状态；
3. 硬切后对视交互逻辑、角色之间视线锚定关系仍需遵守对视防穿帮校验规则。

叙事硬性要求
1. 零放空镜头：判定水镜头标准：无表演、无情绪、无动作、无叙事信息的纯空画面；对话之间的情绪停顿、反应静默，搭配微表情、手部细微肢体动作，属于电影感正常叙事，不属于水镜头；低信息过场画面必须绑定人物肢体动作、微表情表演，禁止纯环境空镜头。
2. 每一秒优先承载：台词 / 肢体动作 / 道具交互 / 情绪变化 / 人物反应表演；拒绝悬念钩子收尾；每个 15 秒镜头结尾做到剧情持续向前推进，**禁止慢拉蓄力、画面定格、BGM骤停留白、悬念留白钩子；推荐使用角色对白或者关键动作完成镜头收尾，直接为下一个镜头承接剧情输入**。
3. 内容忠实度：角色对白 100% 沿用原文；内心独白、旁白仅原文存在才原样取用，绝不增删篡改；超长连贯台词按照铺垫、冲突、反转节点拆分镜头，禁止提速压缩台词。

衔接流畅度升级
1. 下镜头资产、造型、服饰配饰、光影色温、薄雾、地面倒影、环境粒子、视线交互关系 100% 继承上镜头；（剧情硬切模式除外，硬切仅释放肢体姿态、运镜轨迹继承）

叙事效率扩容

**15秒单元实测承载阈值（总时长14.7‑15.3s）**
- 文戏叙事单元（语速1.0x）：承载上限2‑4轮角色对白，允许最多1次0.6‑1s情绪静默，静默必须绑定微表情肢体表演；叙事（台词+动作情绪表演）占比65‑70%，外貌光影细节≤35%；
- 冲突预警单元（语速1.1‑1.2x）：承载上限1‑2句关键台词+一套完整动作交互，降低对白占比，提升动作叙事权重；
- 战斗高潮单元（语速1.2‑1.4x）：承载上限1‑3句短促指令、吐槽短句，以动作音效为主，台词密度降低；
硬性约束：同一个15s镜头内禁止堆砌4句及以上长对白，出现必须拆分镜头，禁止依靠提速挤压内容。

单 15s 片段承载自然语速下的起因 + 冲突 + 推进信息；不强制高密度台词；允许合理对话停顿、情绪静默反应，必须配套微表情表演；删除钩子悬念逻辑；剔除无信息放空水镜头；允许一轮对手回应台词丰富对手戏。

1. 帧间连续性：优先匀速直线 / 标准圆弧运动，单帧位移≤5%；资产光影造型锚点强制继承；继承姿态静态上限 0.8s；运镜接续上镜头末端，禁止重置；铺垫冲突高潮使用中速运镜，冲突镜头小幅加速≤0.4，禁止无目的慢移空镜；动态快门 1/50，消除运动拖影，发丝衣纹道具雕刻 8K 清晰；人物移动轨迹连贯无瞬移；压缩无效过渡姿态，保留情绪表演停顿，不以牺牲人物表达换取紧凑叙事。

15 秒专属底层节奏规则
1. 静态时长上限：固定机位最长 1.2s，必须同步肢体剧情动作或情绪微表演；纯面部特写静态上限 0.5‑1s；继承帧接续姿态静态展示严禁超过 0.8s 阈值。
2. 信息密度：单帧叙事核心元素≥2 项（连贯动作 / 微表情 + 道具变化 / 环境细节）；纯人脸无动作无情绪判定无效水帧；带微表情的对话反应静默不属于无效画面。
3. 运镜功能化：运镜匹配剧情情绪；快推适配冲突升级；平行中速跟拍适配对峙；局部快特写适配线索揭晓；铺垫段中速运镜，高潮动态节奏运镜；全程禁止慢蓄力推移。
4. 时长约束：总时长误差控制`±0.3s`；删除强制提速规则；台词过载优先拆分镜头，不挤压语速；允许镜头内部情绪停顿，禁止无表演空白。
> 停顿分级细化：文戏句间停顿0.3‑0.6s；人物情绪反应静默停顿0.6‑1.0s，静默必须绑定微表情/手部肢体动作；战斗冲突段落，句间停顿压缩至0.2s以内，适配快节奏打斗。

✅4. 语速台词校验：无全局强制提速；语速匹配角色情绪性格；无依靠提速塞入过量台词；参照三类15s单元承载阈值。
✅5. 资产校验：角色道具场景 OCR 匹配，无错配替换。
✅6. 对视校验：角色对白每条标注【对视对象：XX】；说话人视线躯干锁定倾听角色；无看向空白 / 第三方穿帮；独白旁白按需豁免。
✅7. 帧接续校验：选定正确帧接续模式；AI软帧接续模式下资产光影薄雾倒影视线锚点完整继承；起始姿态不冻结＞0.8s；运镜接续末端轨迹；无无理由硬切；硬切保全人物资产光影统一。
✅8. 节奏校验：无极慢蓄力运镜；结尾无悬念钩子定格。
✅9. 时长校验：总时长落在 14.7‑15.3s 区间。
✅10. 标准化字段校验：每个镜头完整填充【五官神态】【服装造型】【场景环境】【光影氛围】【镜头感受】【色彩基调】【镜头语言】【情绪表演备注】。

✅12.镜头模式校验：时间/空间跳转转场，按需开启剧情硬切模式；硬切只保护角色资产光影对视逻辑，不强制锁定肢体姿态、运镜轨迹。

✅15.结尾校验：镜头结尾无慢拉、定格、BGM骤停留白悬念钩子；依靠角色对白或者关键动作推进下一段剧情；过场画面不存在纯空镜头。
